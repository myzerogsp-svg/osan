공용폴더에 두고 여러 사람이 동시에 써도 됩니다.
실행하면 각자 컴퓨터로 복사한 뒤 그 복사본이 열리므로, 한 사람이 켜 있어도 다른 사람이 열 수 있습니다.
공용폴더의 파일을 새것으로 바꾸면 다음에 켤 때 각자 컴퓨터 복사본도 따라 바뀝니다.
제어판에서 고친 지역·센터·라인·상품코드는 공용폴더의 제어판.json 에 저장됩니다. 이 파일은 지우지 마세요.
다른 컴퓨터는 잠시 후 같은 내용이 보이고, 프로그램을 다시 열어도 유지됩니다.

1. 압축을 풀고 생산성보기.exe 를 더블클릭합니다.
   화면.html 은 exe 옆에 그대로 두세요.
   Windows 보호 창이 나오면 실행을 누르세요. 서명되지 않은 새 파일이라 한 번 물어봅니다. 실행 안 함을 누르면 프로그램이 안 열립니다.
2. 화면은 사이트와 같습니다. 위쪽 메뉴는 없습니다.
3. 작업 파일을 누르면 오늘 작업 엑셀과 1·2·3센터 배치표를 고릅니다.
4. 파일 합치기를 누르면 예전 합치기 창이 열립니다.
   1·2·3센터 원본을 고르고 업로드용 엑셀을 저장합니다.
5. 생산성 분석 메뉴의 파일 여러 개 선택으로 날짜_FF1, 날짜_FF2 파일을 고릅니다.
   사람별은 오른쪽 근태양식의 날짜와 소분류 이름을 적은 뒤, 근태표로 올립니다.
6. 출고 분석의 월 파일 올리기, 업로드 만들기는 엑셀 고르는 창이 열립니다. 여러 파일을 한 번에 고를 수 있습니다.
   업로드 만들기는 만든 뒤 저장할 곳을 묻습니다. 취소하면 저장하지 않습니다.
7. 파일을 바꿀 때는 프로그램을 끄지 말고 같은 버튼을 다시 누릅니다.

브라우저의 엑셀 선택은 누르지 마세요. Privacy-i가 막습니다.
파일 합치기 EXE는 따로 받지 않아도 됩니다. 생산성 프로그램 안의 파일 합치기 버튼을 쓰세요.
사이트를 다시 발행하면, 프로그램을 다음 번에 열 때 새 버전을 알아서 받아 다시 열립니다.
안 바뀌면 생산성 EXE를 다시 받아 생산성보기.exe 와 화면.html 만 바꾸세요.
자동 업데이트가 되는 프로그램으로 한 번은 이 압축을 받아 바꿔 두어야 합니다.
제어판.json 은 그대로 두세요.
